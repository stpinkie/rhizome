# Agent Test Reports

Each cloud agent run should write two files here:

- `rhizome-test-report-<os>-<arch>-<agent>-<YYYYMMDD-HHMMSS>.md`
- `rhizome-test-report-<os>-<arch>-<agent>-<YYYYMMDD-HHMMSS>.json`

For example:

- `rhizome-test-report-linux-amd64-agent-1-20260831-120000.md`
- `rhizome-test-report-linux-amd64-agent-1-20260831-120000.json`

Reports are committed so we can track test coverage across different agents and operating systems.
