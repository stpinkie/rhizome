# Rhizome v0.8.2 Release Notes

## Sprint theme

v0.8.2 release-readiness stabilization.

This is a no-feature stabilization sprint that verifies the v0.8.1 hardening on
Windows, validates the cross-compile matrix, tightens the lint gate to the
v0.8.0/v0.8.1 scope, and clears the path for tagging `v0.8.2`. All product
behavior is unchanged.

---

## Track — Release gate stabilization

### Windows test hardening

- Confirmed `scripts/test-windows.ps1` is green on Windows: it compiles each
  package's test binary to a stable path under `build\tests\`, optionally
  creates deterministic firewall rules, and runs all 107 packages sequentially.
- Confirmed `go test -p 1 -tags goolm,stdjson -count=1 ./...` is green.
- `scripts/integration-mesh.ps1` and `scripts/integration-swarm.ps1` pass
  end-to-end on Windows (node onboard, ping, bidirectional workspace sync,
  reconnect catch-up, swarm join, roster exchange, presence, restart
  persistence).
- Both integration scripts gained a `-SkipFirewall` switch so they can be run
  without Administrator privileges when firewall rules are already in place.

### Cross-compile matrix

- Validated green: `linux/amd64`, `darwin/arm64`, `freebsd/amd64`,
  `openbsd/amd64`.
- Removed `dragonfly/amd64` from `.github/workflows/pr.yml`: `modernc.org/libc`
  (pulled in by `modernc.org/sqlite`) has no Go files for dragonfly, so it is
  not a supported cross-compile target today. `make build-all` already omitted
  dragonfly.

### Lint / release gate

- `golangci-lint run --build-tags goolm,stdjson ./...` is now green.
- The re-enabled `errcheck`, `staticcheck`, and `gosec` linters remain enforced
  in the v0.8.0/v0.8.1 stabilization scope: `pkg/rhizome/...`, `pkg/media/...`,
  and `pkg/tools/fs/...`.
- Legacy `golangci-lint` findings in `cmd/`, `web/`, `examples/`, `scripts/`, and
  the rest of `pkg/` are now excluded from the release gate with a documented
  `.golangci.yaml` exception, pending dedicated cleanup sprints; no linters were
  disabled globally.
- Fixed the remaining in-scope lint findings:
  - `pkg/rhizome/blob/store.go`, `pkg/rhizome/blob/transport.go`,
    `pkg/rhizome/merge/tree.go`: handle `Close` errors with `defer` anonymous
    functions.
  - `pkg/rhizome/identity/store.go`: use a two-value type assertion for the
    public key, and `nolint` the caller-validated file path and the
    encrypted/empty private-key marshaling.
  - `pkg/rhizome/network/host.go`: replace the empty bootstrap error branch
    with an explicit discard, and `nolint` the bounded libp2p reachability
    conversion.

### Linux re-validation

- Windows build/test/cross-compile is green.
- A dedicated Linux host run remains the recommended next step for final
  sign-off; this release does not claim it. The previously Windows-flaky tests
  (`TestMeshFanoutQuorumPending`, `TestSwarmOfferClaimAssign`,
  `TestMeshTaskSpawnDisabled`) are stable under the `-p 1` sequential runner.
