# Rhizome v0.4.7 Release Notes

**Focus:** Saved peer management. The Network dashboard now lists persistent mesh peers and lets you untrust or remove them directly, with matching daemon, launcher, and CLI support.

## New Features

- **Daemon `/network/saved-peers` management endpoint**:
  - `pkg/gateway/networkpeers.go` adds `GET/POST/DELETE /network/saved-peers`.
  - `GET` returns `mesh.trusted_peers` and `mesh.bootstrap_peers` merged by peer id, with optional live `connected` and `capability` status.
  - `POST ?action=untrust&peer=<peer-id>` removes the peer from the runtime trust set and `mesh.trusted_peers`.
  - `DELETE ?peer=<peer-id>` untrusts the peer, disconnects it, removes it from `mesh.trusted_peers`, and removes all matching `mesh.bootstrap_peers`.
  - The handler is registered in `pkg/gateway/gateway.go` alongside the existing `/network/status` endpoint.
- **Launcher `/api/network/saved-peers` routes**:
  - `web/backend/api/network.go` adds `GET/POST/DELETE /api/network/saved-peers`.
  - When the daemon is running, the launcher proxies to the daemon endpoint.
  - When the daemon is unavailable, the launcher edits `config.json` directly.
- **Shared saved-peer helpers**:
  - `pkg/rhizome/mesh/savedpeer.go` exposes `BuildSavedPeersResponse`, `BuildSavedPeerForPID`, `UntrustSavedPeer`, and `RemoveSavedPeer`, used by the daemon, launcher, and CLI.
  - `pkg/rhizome/network/host.go` and `pkg/rhizome/mesh/mesh.go` add `Disconnect` wrappers to close a live libp2p connection on Remove.
- **CLI saved-peer commands**:
  - `cmd/rhizome/internal/network/mesh.go` adds `rhizome network saved-peers [--json]` and `rhizome network remove <peer-id>`.
  - `cmd/rhizome/internal/network/command.go` and `cmd/rhizome/internal/mesh/command.go` register the new subcommands.
- **Network dashboard Saved Peers panel**:
  - `web/frontend/src/components/network/saved-peers-panel.tsx` lists saved peers with trust, connection, and capability badges.
  - Each peer has **Untrust** and **Remove** actions; Remove uses an `AlertDialog` confirmation.
  - `web/frontend/src/hooks/use-saved-peers.ts` provides query and mutation hooks that invalidate both saved peers and live network status.
  - `web/frontend/src/components/network/network-page.tsx` integrates the panel below the live Peers and DHT panels.

## Fixes

- Removes the v0.4.6 known limitation: saved peers can now be untrusted or deleted from the dashboard or CLI.

## Known Limitations

- Removing a peer closes the active libp2p connection, but the remote may reconnect if it has the local node as a bootstrap or discovers it via DHT. Remove only stops the local node from initiating outbound connections.
- Custom `?listen=...` still forces the CLI fallback for live status; saved-peer management does not depend on it.

## Build

No CGO on core builds. Use:

```powershell
$env:CGO_ENABLED='0'
go build -tags goolm,stdjson ./...
go test -tags goolm,stdjson ./...
```

For the frontend:

```bash
cd web/frontend
pnpm install
pnpm build:backend
```
