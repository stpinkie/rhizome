# Rhizome v0.7.1 Release Notes (Draft)

## Sprint theme

Tracks 31–32: **Stabilization, Security & Footprint Prototype**.

This is a hybrid sprint after the v0.7.0 Swarm Mode release. Half of the work hardens the build, tests, and security posture; the other half prototypes the two most-requested v0.8.0 features: a `nonetwork` build for tiny boards and a native browser automation tool.

---

## Track 31 — Stabilization & Security

### CI / test hardening

- Fix flaky mesh, swarm, and sync tests by replacing peerstore-based protocol polling with a direct stream probe (`pkg/rhizome/p2putil.OpenProtocolStream`) and then opening the actual call/push/fetch stream with `host.NewStream` under the caller's context.
- Stabilize `scripts/integration-swarm.ps1` and `scripts/integration-swarm.sh` across Windows and Linux.
- Triage `origin/fix-golangci-lint-failure-5375077918160686143` and `origin/freebuff/go-through-the-github-actions-to-ass-vx8djdtz` branches. **Do not merge them blindly** — their diffs relative to `main` currently remove large parts of the v0.7.0 mesh, swarm, and web code and need a manual, surgical review.
- `golangci-lint --build-tags=goolm,stdjson` now reports 0 issues: `.golangci.yaml` disables linters that are incompatible or excessively noisy for this codebase (`exhaustruct_v5`, `gomodguard`, `recvcheck`, `misspell`, and the `govet` `shadow`/`inline` analyzers), `golangci-lint fmt` was applied repo-wide, and the remaining diagnostics (canonical headers, named interface params, predeclared `cap` shadows, dead code, stray `nolint` directives) were fixed.
- `make lint` runs `golangci-lint run --build-tags $(GO_BUILD_TAGS) ./...` plus `scripts/lint-docs.sh`, and fails early with an install hint when golangci-lint is missing. The Makefile `.PHONY` list now covers every phony target. CI is pinned to golangci-lint v2.13.2 (the config requires linters such as `exhaustruct_v5` that older releases do not know).

### Security quick wins

- **SSRF protection**: add a blocklist to network-facing tools (`web_search`, URL-bearing `shell` commands, etc.) preventing access to `10/8`, `172.16/12`, `192.168/16`, `169.254/16`, link-local, and cloud metadata endpoints (`169.254.169.254`).
- **Prompt-injection hardening**: add input validation/sanitization for tool arguments and JSON extraction, rejecting obvious control-character and instruction-injection patterns.
- **Privacy redaction**: add config-driven redaction of API keys, tokens, and common PII patterns from logs and tool outputs.
- **Filesystem sandbox**: ensure `read_file`/`write_file` respect a configurable sandbox directory list, falling back to the workspace.

### Release and docs debt

- Replace `assets/logo.webp` with actual Rhizome branding.
- Replace remaining PicoClaw mascot/slogan/shrimp references in translated READMEs.
- Refresh translated README news sections through v0.7.0.
- Re-enable `.github/workflows/nightly.yml` and/or `docker-build.yml` when release credentials are ready; otherwise document the blocker in `.todo.md`.

## Track 32 — Footprint & Tools Prototype

### Nonetwork build

- Add a `nonetwork` Go build tag and a `make build-nonetwork` target.
- Exclude libp2p, DHT, mesh, and swarm dependencies when the tag is set.
- Add the `nonetwork` target to the cross-compile matrix.
- Measure binary-size and memory-footprint savings and update the build-footprint table in `README.md`.

### Browser automation prototype

- Decide the integration path: native CDP/Playwright Go tool versus wiring the existing `agent-browser` npm skill (`workspace/skills/agent-browser/SKILL.md`).
- Implement a proof-of-concept tool with at least:
  - `browser_open <url>`
  - `browser_snapshot [--interactive]`
  - `browser_click <ref>`
  - `browser_fill <ref> <text>`
  - `browser_screenshot`
- Add unit tests using a headless browser or a mock CDP session.
