# Rhizome v0.8.3 Release Notes

## Sprint theme

Post-validation stabilization for v0.8.2.

This patch release fixes the one genuine Linux unit-test failure, clarifies the
lint configuration, and adds a small-VM validation path. No product behavior
changes.

---

## Track — Post-validation hardening

### `pkg/evolution` test fix

- `TestRuntime_RunColdPathOnce_DraftSaveFailureRollsBackAppliedSkill` no longer
  relies on `os.Chmod(paths.RootDir, 0o555)`, which does not block writes when
  the test runs as root (the common case in Docker containers).
- The test now creates `paths.SkillDrafts` as a directory, which makes
  `SaveDrafts` fail at the write step and exercises the real rollback path.
- `LoadDrafts` treats a directory at the drafts path as an empty draft list, so
  the save attempt is reached and the failure is correctly wrapped as
  `ErrApplyDraftFailed`.

### Lint and release-gate documentation

- Added a header comment to `.golangci.yaml` clarifying that `errcheck`,
  `gosec`, and `staticcheck` are intentionally enabled and only the historical
  legacy debt outside the v0.8.2 stabilization scope is path-excluded.
- Added a "Validation on resource-constrained Linux VMs" section to `AGENTS.md`.

### Small-VM validation path

- `make lint-slim` — lint the v0.8.2 in-scope packages only
  (`pkg/rhizome/...`, `pkg/media/...`, `pkg/tools/fs/...`).
- `make build-core` — cross-compile the core release targets only
  (`linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`,
  `windows/amd64`, `freebsd/amd64`, `openbsd/amd64`).
- `scripts/build-core-targets.sh` — builds each core target and frees the Go
  build cache between them.
- `scripts/validate-small-vm.sh` — builds `cmd/rhizome`, runs `go vet`/`go test`
  on `pkg/evolution` + the in-scope packages, runs `make lint-slim`, then
  `make build-core`. It frees the build cache between heavy phases to stay
  within a ~4 GB root FS.
