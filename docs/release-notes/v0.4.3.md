# Rhizome v0.4.3 Release Notes

**Focus:** Frontend network dashboard — a web UI for live mesh peers and DHT status.

## New Features

- **Network dashboard page** at `/network`:
  - New sidebar group **Network** with a single **Network** entry.
  - Fetches and displays `/api/network/peers` and `/api/network/dht`.
  - Shows local node identity (name, peer ID).
  - Lists connected peers with peer ID, addresses, trusted/untrusted badge, and advertised capabilities (models, skills, agents).
  - Shows DHT status snapshot: rendezvous, rendezvous CID, mode, routing table size, bootstrap peers, discovered peer count, last provide/discover times, and provided/discovered flags.
  - Optional bootstrap multiaddr input so users can specify one or more peers to query against.
  - Manual **Refresh** button and auto-poll every 60 seconds while the page is visible; polling pauses when the tab is hidden.
- **Frontend APIs and hooks**:
  - `src/api/network.ts` types and clients for `getNetworkPeers` and `getNetworkDHT`.
  - `src/hooks/use-network.ts` React Query hook with visibility-aware polling.
- **New frontend components** under `src/components/network/`:
  - `network-page.tsx`, `peers-panel.tsx`, `dht-panel.tsx`, `bootstrap-input.tsx`.
- **Routing and navigation**:
  - New `src/routes/network.tsx` TanStack Router route.
  - Updated `src/routeTree.gen.ts` to register `/network`.
  - New `navigation.network_group` and `navigation.network` i18n keys.
- **Translations**:
  - English and Chinese (zh) strings added.

## Fixes

- No user-facing fixes in this release.

## Known Limitations

- The dashboard still spawns a temporary libp2p node per API call via the backend. Auto-poll is set to 60s and the backend caches results for 5s to limit churn.
- The page is read-only; trust/delegate/spawn actions are not yet available in the UI.

## Build

No CGO on core builds. Use:

```powershell
$env:CGO_ENABLED='0'
go build -tags goolm,stdjson ./...
go test -tags goolm,stdjson ./...
```

For the frontend:

```bash
cd web/frontend
pnpm install
pnpm build:backend
```
