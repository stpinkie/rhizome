# Rhizome v0.8.1 Release Notes

## Sprint theme

Stabilization / release-readiness hardening after v0.8.0.

This patch release fixes the build, test, and lint regressions that surfaced on
Windows and cross-compile targets during the v0.8.0 Linux validation run. No new
features are introduced.

---

## Track — Build, test, and lint hardening

### Reliable stream shutdown

- `pkg/rhizome/stream/reliable.go`: closed the `ReliableConn` close/ACK race.
  `WriteFrame` re-checks for an ACK arriving as `r.done` closes or the write
  deadline fires, and drains `req.ack`/`req.err` before returning
  "reliable conn closed".

### Mesh and swarm test stability

- `pkg/rhizome/mesh/task_test.go`: replaced identify/peerstore waiting with a
  direct `NewStream` probe, which is more reliable under parallel or loaded
  runs.
- `pkg/rhizome/swarm/transport.go`, `agentrpc.go`, `agenttask.go`, `mesh.go`:
  raised protocol timeouts from 5 seconds to 15–30 seconds to tolerate slow
  libp2p identify and mDNS storms.
- `pkg/rhizome/swarm/tracks_test.go`, `queue_maturity_test.go`: lengthened
  swarm claim windows and increased retry-test timeouts for loaded test runs.
- `pkg/rhizome/transport.go`: widened the `AnnounceHead` test bound from 20 s
  to 30 s and documented the ~15.5 s worst-case retry budget.

### Lint / build cleanups

- `pkg/tools/fs/filesystem.go`: removed unused `//nolint:gosec` directives.
- `pkg/rhizome/mesh/taskstore_test.go`: added reads of mutated snapshot fields
  so `govet` `unusedwrite` no longer triggers.
- `pkg/rhizome/swarm/queue.go`: renamed `max` to `maxOffers` to avoid the
  predeclared identifier.
- `.github/workflows/pr.yml` and `AGENTS.md`: standardized the full test command
  to `go test -p 1 -tags goolm,stdjson ./...` to avoid libp2p/mDNS and
  stream-reset contention on Windows.

### Watcher hardening

- `pkg/rhizome/sync/watcher.go`:
  - `isGitInternal()` replaces `strings.HasPrefix(rel, ".git")`, avoiding false
    matches for `.github`, `.gitignore`, and `.gitattributes`.
  - Added `WatcherOption` and `WithOnError`.
  - Made `Close()` idempotent with `sync.Once`.
  - Flushes pending changes during shutdown.
  - Surfaces `fsnotify` and `WalkDir` errors through `onError`.
  - Corrected the misleading symlink comment.
- `pkg/rhizome/sync/syncer.go`: wires `WithOnError` into `logger.WarnCF`.

### Task and swarm state safety

- `pkg/rhizome/mesh/taskstore.go`: `snapshot()` shallow-copies `*ToolResult`
  into a new pointer, preventing caller mutation from corrupting stored state.
- `pkg/rhizome/mesh/taskstore_test.go`: reworked
  `TestTaskStoreSnapshotsAreIndependent` to finish a task, mutate `ForLLM`, and
  verify a fresh owned copy stays unchanged.
- `pkg/rhizome/swarm/swarm.go`: replaced implicit `MemberInfo(m)` conversion
  with explicit field copying and added a compile-time shape guard.

### Media cleanup and test concurrency

- `pkg/media/store.go`: `removeFileAndEmptyDir` now removes empty directories
  only when they are inside `media.TempDir()`, never the shared media temp root,
  OS temp root, or caller-owned directories outside the media temp tree.
- `pkg/media/store_test.go`: uses per-goroutine subdirectories in
  `TestConcurrentSafety` to avoid races between cleanup and file creation.
- `pkg/media/video.go`: added `//nolint:gosec` rationale comments for local
  ffmpeg/ffprobe paths and tightened extracted-frame directory permissions from
  `0755` to `0750`.

### Configuration and channel registration

- `pkg/config/config.go`: added `SkillPullAllowSuspicious`.
- `pkg/config/register_channel_settings_test.go`: added factory-map
  snapshot/restore helpers, uses test-specific registration names, and prevents
  tests from leaking global channel registrations.

## Verification

- `go build -tags goolm,stdjson ./...` — green.
- `go test -p 1 -tags goolm,stdjson -count=1 ./...` — green (sequential package
  execution to avoid libp2p/mDNS contention on Windows).
- `golangci-lint run --build-tags goolm,stdjson` — green on the v0.8.0
  in-scope packages (`pkg/rhizome/mesh`, `swarm`, `stream`, `pair`, `blob`,
  `network`, `sync`, `merge`, `identity`, `pkg/media`, `pkg/tools/fs`).
- `scripts/integration-swarm.ps1` and `scripts/integration-mesh.ps1` — green
  end-to-end on Windows.
- Cross-compile smoke tests — green for `linux/amd64`, `darwin/arm64`,
  `freebsd/amd64`, `openbsd/amd64`.

## Compatibility
